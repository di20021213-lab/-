# Проверка Озона на Windows

Ради этого шага мы отчасти и переезжали: посмотреть, пустит ли Озон браузер,
когда система не Linux. Туннель для этого **не нужен** — Озон открывается
напрямую с твоего домашнего адреса, туннель работает только для Telegram.

## 1. Забрать проект целиком

Отдельные файлы через браузер тут не подойдут: `ozon_check.py` тянет за собой
весь пакет `avito_watcher`. Нужен весь проект.

**С Git** (правильный путь, дальше всё обновляется одной командой):

```powershell
cd C:\
git clone https://github.com/di20021213-lab/- avito-watcher
cd C:\avito-watcher
git checkout claude/avito-gpu-parser-mmp6rr
```

**Без Git** — архивом:

```powershell
Invoke-WebRequest -Uri "https://github.com/di20021213-lab/-/archive/refs/heads/claude/avito-gpu-parser-mmp6rr.zip" -OutFile C:\avito.zip
```

```powershell
Expand-Archive C:\avito.zip -DestinationPath C:\ -Force
```

Папка появится с длинным именем — переименуй в `C:\avito-watcher`.

## 2. Подготовить окружение

```powershell
.\deploy\windows\setup.bat
```

Ставит зависимости и браузер, минут пять. **Конфиг и база для этого не нужны**,
так что бэкап можно забрать позже.

## 3. Проверить Озон

```powershell
.\deploy\windows\ozon.bat
```

Что означает вывод:

| Результат | Что это значит |
|---|---|
| `прочитано 4 из 4` | Озон пустил. Гипотеза про Linux подтвердилась, строим слежение |
| `КАПЧА` | Дело не в системе. Дальше — пункт 4 |
| `заглушка` | Промежуточный случай, покажи вывод мне |

На Linux было **0 из 4** и капча — вот с чем сравниваем.

## 4. Если снова капча — разгадать руками

На Windows это просто: открывается обычное окно браузера.

```powershell
.\deploy\windows\ozon_captcha.bat "https://ozon.ru/t/l1ZC6Ti"
```

Двигаешь ползунок мышкой. Скрипт сам заметит, что капча пройдена, покажет товар
с ценой и сохранит сессию в папке `ozon-profile`.

После этого проверки гоняй **тем же видимым браузером**:

```powershell
set OZON_HEADLESS=0
.venv\Scripts\python ozon_check.py --file ozon-links.example.txt
```

Сессия привязана не только к кукам, но и к отпечатку браузера: в скрытом режиме
он другой, и Озон переспросит.

## Чего ждать

Скажу честно: мой прогноз — капча останется. Операционная система в оценке
«бот или человек» весит мало, а главный признак — что браузером управляет
программа, и на Windows он ровно тот же. Но проверить дёшево, а я в этой
истории уже ошибался, так что померяем.

Если капча будет переспрашивать каждые пару часов — затея не стоит свеч, и
честнее включить отслеживание цены у самого Озона: избранное → уведомление о
снижении цены.
