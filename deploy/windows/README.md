# Бот на Windows

Код кроссплатформенный — переписывать ничего не нужно. Linux-специфична была
только обвязка: systemd, autossh, доступ по SSH. Ниже — чем её заменить.

> Ставишь систему прямо сейчас? Открой сначала
> [CHECKLIST.md](CHECKLIST.md) — там порядок действий, и первый шаг делается
> ДО того, как ты сотрёшь Linux.

## Если это Windows 11 LTSC

Хороший выбор для всегда включённой машины: нет Store, рекламы и принудительных
обновлений функций. Но четыре вещи отличаются от обычной Windows.

**Нет Store и winget.** Python ставить вручную с python.org — как и написано
ниже. Никаких `winget install` не будет.

**Сервер OpenSSH ставится не всегда через «Параметры».** На LTSC список
дополнительных компонентов бывает пуст. Тогда из PowerShell от администратора:

```powershell
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Set-Service sshd -StartupType Automatic
Start-Service sshd
```

Клиент `ssh.exe` (он нужен туннелю) есть по умолчанию — ставить не надо.

**Удалённый рабочий стол работает.** LTSC собран на Enterprise, так что RDP
доступен, в отличие от Home. Но ты за CGNAT: снаружи он всё равно виден не
будет, и понадобится тот же обратный туннель на зарубежный сервер — просто
пробрасывать порт 3389 вместо 22. Выбирай, что удобнее с телефона.

**Требования Windows 11 никуда не делись** — TPM 2.0 и Secure Boot. Мини-ПК,
на котором спокойно жил Linux, может не пройти проверку. Выясни это до того,
как сотрёшь рабочую систему: сначала забери с неё `seen.sqlite3`, `.env`,
`config.yaml` и ключ SSH (список ниже), а лучше сними образ диска целиком.

## Быстрый старт

1. Поставь [Python](https://www.python.org/downloads/) и **обязательно** отметь
   при установке галочку «Add python.exe to PATH».
2. Положи папку с ботом куда угодно, например `C:\avito-watcher`.
3. Скопируй туда с мини-ПК три вещи (см. «Переезд» ниже) — или создай заново:
   `config.yaml`, `.env`, `seen.sqlite3`.
4. Двойной щелчок по `deploy\windows\run.bat`.

Первый запуск ставит зависимости и браузер — это минут пять и около 200 МБ.
Дальше запускается за секунды.

Проверить настройку, ничего не отправляя: `deploy\windows\check.bat`.

## Переезд с мини-ПК: что забрать обязательно

| Файл | Зачем |
|---|---|
| `seen.sqlite3` | **Самое важное.** База виденных объявлений. Без неё бот сочтёт запуск первым и либо промолчит целый цикл, либо пришлёт всё заново |
| `.env` | Токен бота, chat_id, адрес прокси |
| `config.yaml` | Твои поиски, цены, стоп-слова |
| `~/.ssh/id_ed25519` | Ключ к зарубежному серверу — нужен туннелю. Класть в `%USERPROFILE%\.ssh\` |

Папку `browser-profile` брать не надо: она соберётся заново, а куки от Linux
на Windows всё равно выглядят подозрительно.

## Telegram: туннель

`api.telegram.org` напрямую не открывается, поэтому нужен SOCKS-прокси —
ровно как сейчас на Linux. Замена autossh — `tunnel.bat`: впиши в него адрес
своего сервера и запусти. Строку `TELEGRAM_PROXY` в `.env` менять не нужно.

Проверить, что канал жив: `.venv\Scripts\python test_notify.py`.

## Автозапуск: Планировщик задач

systemd на Windows нет, его роль играет Планировщик (Win+R → `taskschd.msc`).
Нужны **две** задачи — туннель и сам бот:

1. «Создать задачу» (не «простую задачу»).
2. Вкладка «Общие»: **«Выполнять вне зависимости от регистрации пользователя»** —
   иначе задача не переживёт выход из системы. Галочка «Выполнить с наивысшими
   правами» не нужна.
3. «Триггеры»: «При запуске компьютера». Полезно добавить «Повторять задачу
   каждые 5 минут» бессрочно — Планировщик не станет плодить копии, но поднимет
   упавшую.
4. «Действия»: запуск программы — полный путь к `tunnel.bat` (для первой задачи)
   и к `run.bat` (для второй). В поле «Рабочая папка» укажи папку бота.
5. «Условия»: снять «Запускать только при питании от сети».

Порядок важен: туннель должен подняться раньше бота. Если бот стартанул первым,
он просто не достучится до Telegram и напишет об этом в лог — переживёт.

## Сон: выключить обязательно

Windows по умолчанию усыпляет компьютер, и спящий бот ничего не проверяет.
Параметры → Система → Питание → «Сон» → **«Никогда»**. Отдельно проверь там же
«Экран» — его можно гасить, это не мешает.

## Доступ с телефона

На Linux это был SSH. В Windows его можно включить штатно:
Параметры → Приложения → Дополнительные компоненты → «Сервер OpenSSH».
После установки:

```
Set-Service sshd -StartupType Automatic
Start-Service sshd
```

Дальше — тот же обратный туннель на зарубежный сервер, что и сейчас, только
поднимает его `tunnel.bat` (допиши в него `-R 127.0.0.1:2222:127.0.0.1:22`).
Альтернатива без SSH — «Удалённый рабочий стол», если версия Windows не
Home.

## Как понять, что бот работает

Так же, как на Linux, — по сводке в Telegram. `heartbeat_every: "20m"` в
`config.yaml` заставит его писать «я жив» после каждой проверки, и лезть в
логи не придётся вовсе. Сам лог — в окне `run.bat`.

## exe

`build_exe.bat` собирает `dist\avito-watcher\` — папку с exe, которой не нужен
Python. **Запускать сборку надо на самой Windows:** PyInstaller не умеет делать
Windows-exe на Linux.

Честно говоря, для своей же машины exe скорее мешает: обновление превращается
из `git pull` в пересборку, а выигрыш только в том, что не надо ставить Python.
Имеет смысл, если захочешь отдать бота кому-то ещё.
