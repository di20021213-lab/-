# Переезд на Windows: порядок действий

Список рассчитан на то, что ты стоишь у машины с флешкой. Пункты идут в том
порядке, в котором их надо делать; шаг 1 необратим, если его пропустить.

## 1. ДО установки: забрать данные с Linux

```bash
cd ~
tar czf avito-backup.tgz \
    avito-watcher/seen.sqlite3 \
    avito-watcher/.env \
    avito-watcher/config.yaml \
    .ssh/id_ed25519 .ssh/id_ed25519.pub
scp avito-backup.tgz root@ТВОЙ_СЕРВЕР:~/
```

Что и зачем:

| Файл | Что будет без него |
|---|---|
| `seen.sqlite3` | Бот сочтёт запуск первым: молча запомнит всю выдачу и не пришлёт ничего целый цикл |
| `.env` | Заново доставать токен у @BotFather и chat_id |
| `config.yaml` | Заново собирать поиск, цены и стоп-слова — на ссылку Авито ушёл целый день |
| `id_ed25519` | Заново заводить ключ на сервере, а туннель без него не поднимется |

Проверь, что архив реально долетел: `ssh root@ТВОЙ_СЕРВЕР ls -la avito-backup.tgz`.

## 2. Положить на флешку драйвер сети

Самая обидная поломка: Windows встала, а сетевой карты не видит — и скачать
драйвер нечем, потому что нет сети. Посмотри модель заранее:

```bash
lspci | grep -iE 'ethernet|network'
```

Найди драйвер под эту карту на сайте производителя мини-ПК и **скопируй на
флешку отдельной папкой** уже после того, как Rufus её запишет. Займёт пять
минут, а спасает от поездки за вторым компьютером.

## 3. Записать флешку

Rufus: схема разделов **GPT**, целевая система **UEFI**. Образ — LTSC.

## 4. UEFI: единственная возможность это сделать

Ты у машины с клавиатурой — потом такой возможности не будет, удалённо в UEFI
не попасть. Включить:

- **TPM** — у Intel называется PTT, у AMD fTPM. Без него Windows 11 откажется ставиться.
- **Secure Boot** — если он серый, сначала выключи CSM/Legacy и загрузи Restore Default Keys.
- **Restore on AC Power Loss = Power On** — чтобы после отключения света машина поднялась сама. Для бота, живущего без монитора, это важнее всего остального в этом списке.

Заодно посмотри, какая клавиша вызывает меню загрузки (обычно F7, F11, F12 или Esc).

## 5. Установка

На экране выбора диска удали **все** существующие разделы, выбери
неразмеченное место и жми «Далее» — Windows сама создаст нужное. LTSC не
требует учётной записи Microsoft, локальная заводится сразу.

Пароль локальной учётки поставь нормальный: если включишь RDP, он станет
единственной защитой.

## 6. Сразу после установки, не отходя от машины

1. **Проверь сеть.** Не работает — ставь драйвер с флешки (шаг 2).
2. **Проверь TPM:** Win+R → `tpm.msc` → должно быть «TPM готов к использованию».
3. **Выключи сон:** Параметры → Система → Питание → Сон → «Никогда».
   Экран гасить можно, это не мешает.
4. **Включи удалённый доступ** — RDP или OpenSSH Server (см. README.md рядом).
   Проверь, что заходишь с телефона, ПОКА ты у машины.

Только после этого можно уходить.

## 7. Бот

Дальше — `README.md` в этой же папке: Python, `run.bat`, туннель, Планировщик.
Распаковать сохранённое:

```
tar xzf avito-backup.tgz
```

и разложить `seen.sqlite3`, `.env`, `config.yaml` в папку бота, а ключ — в
`%USERPROFILE%\.ssh\`.

## Про лицензию

LTSC распространяется по корпоративной лицензии, ключ от обычной Windows 11 к
нему не подойдёт. Легально попробовать можно ознакомительным образом с сайта
Microsoft — он работает 90 дней.
