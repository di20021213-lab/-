# Готовый сервер для Windows

`kolhoz-server-win-x64.zip` — сервер игры одним файлом. Внутри архива
`kolhoz-server.exe`, а внутри него: код сервера, база, клиентская страница
и вся графика. Ставить на машину ничего не нужно — ни Node, ни модулей.

## Как запустить

1. Распакуйте архив в любую папку.
2. Запустите `kolhoz-server.exe` двойным кликом. Откроется чёрное окно —
   пока оно открыто, игра работает.
3. В окне будут адреса. Себе — `http://localhost:3000`, игрокам — адрес
   вида `http://192.168.х.х:3000`.
4. Чтобы игроки из вашей сети достучались, один раз запустите
   `windows\3-open-firewall.bat` от имени администратора.

Рядом с exe появится папка `var` с базой — это и есть все аккаунты и хозяйства.
Резервная копия это копия папки `var`.

## Настройки

Создайте рядом с exe файл `.env` (образец — `.env.example` в корне проекта):

```
PORT=3000
PUBLIC_URL=http://192.168.1.50:3000
REQUIRE_EMAIL_VERIFY=false
```

`PUBLIC_URL` должен совпадать с адресом, по которому заходят игроки, иначе
ссылки в письмах приведут их на собственный localhost. `REQUIRE_EMAIL_VERIFY=false`
пускает в игру сразу после регистрации — годится, когда играете в своей сети
и почтового сервера нет.

## Игрокам

Ставить нечего: клиент — браузер. Дайте им адрес или файл `windows\6-play.bat`,
который спросит адрес, запомнит его и откроет игру.

## Пересобрать самому

```bash
node tools/build-exe.js win      # или both — вместе с версией под Linux
```

Размер exe около 88 МБ: большую часть занимает сам Node внутри.
