# PDF в Word — распознавание сканов без интернета

Программа превращает отсканированный PDF (или JPG/PNG/TIFF) в **настоящий
редактируемый документ Word**, а не в картинки, вставленные в .docx:

- текст распознаётся (русский, английский), его можно править и копировать;
- **таблицы** с линиями становятся таблицами Word: те же столбцы и
  объединённые ячейки, а таблица, перешедшая на следующую страницу, склеивается
  в одну;
- сохраняются абзацы, красная строка, выравнивание (по ширине, по центру,
  справа), жирный шрифт, подчёркивание, размер шрифта, межстрочный интервал;
  размер шрифта подбирается так, чтобы текст ложился в те же строки и ячейки,
  что и на скане;
- бланки остаются бланками: линии «________» с подписями под ними
  («(должность)», «(подпись)»), блок подписей в колонки, клетки кодов справа
  с надписями «Форма по ОКУД», «по ОКПО» напротив своих клеток, высота строк
  таблиц как в оригинале;
- номера строк и количества в таблицах дочитываются отдельно, английские
  названия и артикулы (Lenovo, Samsung, KX-TS2358RU) распознаются латиницей;
- перевёрнутые и лежащие боком страницы поворачиваются сами, перекос скана
  выравнивается, альбомные листы остаются альбомными;
- синие печати и подписи стираются перед распознаванием, поэтому в тексте нет
  мусора;
- номера страниц убираются, текст идёт сплошным потоком;
- **интернет не нужен**: движок Tesseract 5 и модели для русского и английского
  уже внутри программы.

## Как скачать

1. Откройте страницу сборок:
   https://github.com/di20021213-lab/-/actions/workflows/pdf2word.yml
   (вкладка **Actions** → слева **PDF to Word - build EXE**).
2. Нажмите на верхний прогон с зелёной галочкой.
3. Внизу, в разделе **Artifacts**, скачайте **PDFtoWord** — это zip-архив с
   файлом `PDFtoWord.exe` (нужно войти в GitHub). Распакуйте его куда удобно.
   Архив хранится на GitHub 90 дней — сохраните `PDFtoWord.exe` у себя.

Если антивирус ругается на одиночный .exe, скачайте **PDFtoWord-portable**:
это та же программа папкой, запускать `PDFtoWord-portable.exe` внутри.

При первом запуске Windows может показать «Windows защитила ваш компьютер» —
нажмите «Подробнее» → «Выполнить в любом случае» (у программы нет платной
цифровой подписи).

## Как пользоваться

1. Запустите `PDFtoWord.exe`.
2. Перетащите PDF в окно (или нажмите **«Выбрать файл…»** и затем
   **«Распознать»**). Можно сразу несколько файлов, а можно перетащить PDF
   прямо на значок программы.
3. Дождитесь конца: полоска показывает ход работы, обычно 5–15 секунд на
   страницу (первый запуск самого .exe занимает несколько секунд — он
   распаковывается).
4. Готовый `.docx` сохраняется **рядом с исходным файлом**, с тем же именем.
   Программа предложит сразу открыть его.

Галочка «Убирать синие печати и подписи» включена по умолчанию. Если в
документе есть важный текст синим цветом, снимите её.

## Советы для лучшего результата

- Сканируйте с разрешением 300 dpi, в оттенках серого или в цвете.
- Чем ровнее и чище скан, тем меньше ошибок: на хорошем скане ошибок почти нет,
  на плохой ксерокопии их будет больше.
- После распознавания проверьте места, где текст был закрыт печатью или
  подписью: там возможны ошибки в отдельных буквах.

## Ограничения

- Рукописный текст не распознаётся.
- Печати, подписи и картинки в документ не переносятся (только текст и
  таблицы).
- Шрифт ставится Times New Roman. Сложная вёрстка (журналы, многоколоночный
  текст) может потребовать ручной правки.
- Таблицы без линий распознаются как текст с табуляцией.

## Для разработчиков

```
pdf2word/            ядро
  engine.py          запуск Tesseract (через stdin/stdout, работает с русскими путями)
  imageops.py        страницы PDF/картинок, поворот, выравнивание, удаление печатей
  tables.py          поиск таблиц по линиям, объединённые ячейки
  layout.py          строки → абзацы, колонки, выравнивание, жирный, размер шрифта
  pipeline.py        конвейер страницы, склейка страниц
  docxwriter.py      запись .docx
pdf2word_app.py      окно программы (Tkinter, перетаскивание — tkinterdnd2)
tests/               генератор тестового скана и проверка результата
tools/make_icon.py   значок программы
```

Запуск из исходников (нужен установленный Tesseract с моделью `rus`):

```
pip install -r requirements.txt
python pdf2word_app.py              # окно
python -m pdf2word скан.pdf         # командная строка
```

Сборка .exe идёт в GitHub Actions (`.github/workflows/pdf2word.yml`) при каждом
изменении кода в ветке: Tesseract (сборка UB Mannheim) и модели `tessdata_best`
скачиваются и вшиваются внутрь, затем собранная программа проверяется на
тестовом скане в папке с русскими буквами в пути.
