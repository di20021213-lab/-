# Локальный ИИ-помощник для команд

Программа, которая работает **у вас на компьютере** и выполняет то, что вы ей напишете обычным языком.
Вы просите — ИИ подбирает команду, показывает её, спрашивает разрешения, выполняет, смотрит на результат и отвечает.

```
~
> сколько свободного места на дисках?

Проверяю свободное место на всех дисках
$ Get-PSDrive -PSProvider FileSystem
Выполнить? [Enter = да / н = нет / в = всегда да / или напишите, что сделать иначе]:

Name  Used (GB)  Free (GB) Root
----  ---------  --------- ----
C        180,23      57,41 C:\
D        402,10     529,77 D:\

На диске C свободно 57 ГБ, на диске D — 530 ГБ.
```

- Модель работает локально через [Ollama](https://ollama.com): ничего не уходит в интернет, ничего не нужно оплачивать.
- Работает на **Windows** (PowerShell), **Linux** и **macOS** (bash).
- Нужен только Python — никаких дополнительных библиотек.
- Перед каждой командой спрашивает подтверждение. Опасные команды (удаление папок, форматирование, выключение компьютера) — только после того, как вы напишете «да».

## Установка на Windows

1. **Python.** Скачайте с [python.org/downloads](https://www.python.org/downloads/) и установите.
   При установке поставьте галочку **«Add Python to PATH»**.
2. **Ollama.** Скачайте с [ollama.com/download](https://ollama.com/download) и установите.
   После установки она сама работает в фоне (значок ламы возле часов).
3. **Этот помощник.** На странице репозитория нажмите **Code → Download ZIP** и распакуйте архив в любую папку.
4. **Запуск.** Дважды щёлкните по `start.bat`.
   При первом запуске помощник предложит скачать модель (около 4,7 ГБ) — нажмите Enter и подождите.

## Установка на Linux / macOS

```bash
# 1. Ollama
curl -fsSL https://ollama.com/install.sh | sh     # на macOS можно просто скачать приложение с сайта

# 2. Помощник
git clone https://github.com/di20021213-lab/-.git ai-helper
cd ai-helper
./start.sh
```

Python 3.8+ на Linux и macOS обычно уже установлен.

## Что можно просить

- «покажи, какие программы сейчас больше всего грузят процессор»
- «найди в папке Загрузки все файлы больше 1 ГБ»
- «создай на рабочем столе папку Проекты и в ней файл заметки.txt с текстом "привет"»
- «какой у меня IP-адрес?»
- «открой ютуб в браузере»
- «переименуй все .jpeg в этой папке в .jpg»
- «сколько места занимает папка Документы?»

ИИ может сделать несколько шагов подряд: выполнить команду, увидеть ошибку, исправить её и попробовать снова.

## Как отвечать на вопрос «Выполнить?»

| Что ввести | Что произойдёт |
|---|---|
| Enter (или `д`) | выполнить команду |
| `н` | отменить |
| `в` | выполнить и дальше не спрашивать (авто-режим) |
| любой текст | не выполнять, а передать ваш комментарий ИИ, например: «нет, только в папке Документы» |

## Команды внутри помощника

| Команда | Что делает |
|---|---|
| `/помощь` | список команд |
| `/авто` | включить/выключить выполнение без подтверждения (опасные команды всё равно спросят «да») |
| `/сброс` | забыть историю разговора |
| `/модель ИМЯ` | сменить модель, например `/модель qwen2.5:3b` |
| `!команда` | выполнить команду сразу, без ИИ, например `!dir` |
| `выход` | закрыть программу |
| Ctrl+C | остановить текущую команду или ответ ИИ |

## Какую модель выбрать

По умолчанию используется `qwen2.5:7b` — хорошо понимает русский и умеет выполнять команды.

| Модель | Размер | Кому подойдёт |
|---|---|---|
| `qwen2.5:3b` | ~2 ГБ | слабый компьютер (8 ГБ памяти), но и ошибается чаще |
| `qwen2.5:7b` | ~4,7 ГБ | **по умолчанию**; 16 ГБ памяти или видеокарта от 6 ГБ |
| `qwen3:8b` | ~5 ГБ | умнее, но отвечает медленнее (сначала «думает») |
| `qwen2.5:14b` | ~9 ГБ | мощный компьютер (32 ГБ памяти или видеокарта от 12 ГБ), ошибается реже всех |
| `llama3.1:8b` | ~4,9 ГБ | альтернатива, по-русски чуть хуже |

Модель должна поддерживать «tools» (вызов инструментов) — все модели из таблицы поддерживают.
Запустить с другой моделью: `start.bat -m qwen2.5:3b` (или `./start.sh -m qwen2.5:3b`), либо во время работы командой `/модель qwen2.5:3b`.

## Настройки запуска

```
python agent.py [просьба] [-m МОДЕЛЬ] [--auto] [--timeout СЕКУНДЫ] [--ctx ТОКЕНЫ] [--host АДРЕС]
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `просьба` | — | выполнить одну просьбу и выйти: `python agent.py покажи свободное место` |
| `-m`, `--model` | `qwen2.5:7b` | модель Ollama (или переменная окружения `AGENT_MODEL`) |
| `--auto` | выключено | выполнять без подтверждения (опасные команды всё равно спросят) |
| `--timeout` | 300 | через сколько секунд остановить зависшую команду |
| `--ctx` | 8192 | сколько текста помнит модель; больше — умнее в длинных задачах, но больше расход памяти |
| `--host` | `http://localhost:11434` | адрес Ollama, если она на другом компьютере |

## Безопасность

- Помощник выполняет команды **с правами вашего пользователя**. Не запускайте его от имени администратора без необходимости.
- Локальные модели иногда ошибаются. **Читайте команду перед тем, как нажать Enter**, особенно в авто-режиме.
- Каждая команда запускается отдельно и не ждёт ввода с клавиатуры. Если команда зависла — нажмите Ctrl+C, или она остановится сама через 5 минут.

## Если что-то не работает

- **«Не получается подключиться к Ollama»** — Ollama не запущена. На Windows запустите её из меню «Пуск», на Linux выполните `ollama serve`.
- **«Модель не умеет выполнять команды (does not support tools)»** — выберите модель из таблицы выше.
- **Отвечает очень медленно** — возьмите модель поменьше: `/модель qwen2.5:3b`.
- **ИИ придумывает ерунду или путается** — напишите `/сброс` и сформулируйте просьбу заново, конкретнее. Или возьмите модель побольше.
- **`python` не найден (Windows)** — переустановите Python с галочкой «Add Python to PATH».
