# Avito GPU Watcher 🎮🔔

Бот следит за **новыми объявлениями по видеокартам на Авито** и мгновенно шлёт
уведомление в **Telegram** (фото, цена, город, ссылка), как только появляется
свежее объявление по твоим фильтрам. Ты открываешь его первым и пишешь продавцу сам.

> Такой подход (уведомления тебе, а не авторассылка продавцам) — надёжный и
> безопасный: не нарушает правила Авито и не рискует баном аккаунта.
> Подробнее см. раздел [«Важно»](#важно).

---

## Как это работает

1. Playwright (Chromium) заходит на страницу поиска Авито, отсортированную «по дате».
2. Из выдачи вытаскиваются объявления по стабильным атрибутам `data-marker`.
3. ID уже виденных объявлений хранятся в SQLite → определяем, что появилось нового.
4. По каждому новому (прошедшему фильтры) объявлению шлётся сообщение в Telegram.

При первом запуске бот **запоминает текущую выдачу без уведомлений** (чтобы не
завалить тебя старыми объявлениями), а дальше шлёт только новинки.

## Установка

Нужен Python 3.10+.

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Браузер для Playwright (один раз)
playwright install chromium
```

## Настройка

### 1. Создай Telegram-бота

1. Напиши [@BotFather](https://t.me/BotFather) команду `/newbot`, задай имя.
2. Скопируй **токен** вида `123456789:AA...`.

### 2. Заполни секреты

```bash
cp .env.example .env
```

Впиши в `.env` свой `TELEGRAM_BOT_TOKEN`. Затем узнай свой `chat_id`:

```bash
python get_chat_id.py     # сначала напиши своему боту любое сообщение в Telegram
```

Скопируй показанный `chat_id` в `.env` (`TELEGRAM_CHAT_ID=...`).

### 3. Задай поиски

```bash
cp config.example.yaml config.yaml
```

Самый надёжный способ задать фильтры — **настроить их прямо на avito.ru**
(модель, цена, город, состояние), **отсортировать «по дате»** и вставить
итоговый URL в `config.yaml`:

```yaml
searches:
  - label: "Видеокарты 200–2000 ₽, свежие"
    url: "https://www.avito.ru/moskva/.../videokarty?pmin=200&pmax=2000&s=104"
    min_price: 200
    max_price: 2000
    max_age: "1h"          # только опубликованные не позже часа назад
    exclude_keywords: ["обмен", "на запчасти", "не работает"]
```

Полезные параметры в самом URL Авито:
- `s=104` — сортировка «по дате» (новые сверху). Оставляй всегда.
- `pmin=` / `pmax=` — цена от/до. Продублируй сюда свой диапазон — Авито отдаст меньше лишнего.

#### Фильтры на нашей стороне (поверх URL)

| Параметр | Пример | Что делает |
|---|---|---|
| `min_price` / `max_price` | `200` / `2000` | Ценовой диапазон. Объявления **без цены** («договорная») при заданном диапазоне отсеиваются — они вне диапазона. |
| `max_age` | `10m`, `20m`, `1h`, `2h`, `1d` | **Свежесть**: не старше N. Понимает и «20 мин», «2 часа», «день»; голое число = минуты. Бот разбирает даты Авито: «5 минут назад», «час назад», «вчера в 14:30», «сегодня, 09:15», «12 августа». |
| `keywords` | `["3060"]` | В заголовке должно быть хотя бы одно из слов. |
| `exclude_keywords` | `["обмен"]` | Если встречается — пропускаем. |

Про `max_age` важно знать две вещи:

- **`max_age` должен быть больше `poll_interval_max`**, иначе объявление может
  «состариться» между двумя проверками. Для `max_age: 10m` поставь интервал ~60–120 сек.
- **Первый запуск.** Без `max_age` бот молча запоминает текущую выдачу и дальше шлёт
  только новое. С `max_age` — наоборот, **сразу пришлёт всё, что подходит по свежести**
  (ради этого его обычно и ставят), остальное просто запомнит.
- Если дату не удалось разобрать (Авито сменил формат), объявление **не отсеивается**:
  оно всё равно новое для нас (его ID не было в базе). Лучше лишний раз показать,
  чем молча потерять выгодное.

## Запуск

```bash
python -m avito_watcher.main
```

Бот пришлёт в Telegram «✅ Бот запущен …» и начнёт присылать новые объявления.
Останавливается по `Ctrl+C`.

### Через Docker

```bash
docker build -t avito-watcher .
docker run --rm \
  -v "$PWD/.env:/app/.env:ro" \
  -v "$PWD/config.yaml:/app/config.yaml:ro" \
  -v "$PWD/seen.sqlite3:/app/seen.sqlite3" \
  avito-watcher
```

### Как фоновый сервис (Linux, systemd)

Пример юнита `/etc/systemd/system/avito-watcher.service`:

```ini
[Unit]
Description=Avito GPU Watcher
After=network-online.target

[Service]
WorkingDirectory=/opt/avito-watcher
ExecStart=/opt/avito-watcher/.venv/bin/python -m avito_watcher.main
Restart=always
RestartSec=15

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now avito-watcher
```

## Настройки (config.yaml → settings)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `poll_interval_min` / `poll_interval_max` | 90 / 180 | Пауза между проверками, сек (берётся случайное значение из диапазона) |
| `headless` | `true` | `false` — показать окно браузера (отладка) |
| `max_notifications_per_cycle` | 15 | Предохранитель от спама при большом наплыве |
| `request_timeout_ms` | 45000 | Таймаут загрузки страницы |
| `user_agent` | — | Переопределить User-Agent |

Секреты и прокси задаются в `.env`: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `PROXY`.

## Важно

- **Авито активно защищается от ботов.** Если увидишь в логах «антибот/капча» —
  запускай из **российского IP** или через `PROXY` (рекомендуется резидентный RU-прокси),
  увеличь `poll_interval_*`, не ставь слишком частые проверки.
- **Вёрстка Авито меняется.** Парсинг опирается на атрибуты `data-marker`
  (они относительно стабильны), но при поломке селекторы, возможно, придётся
  поправить в `avito_watcher/scraper.py`.
- **Уважай правила площадки.** Инструмент шлёт уведомления **тебе** и не
  рассылает сообщения продавцам автоматически. Автоответы продавцам —
  нарушение правил Авито и почти гарантированный бан аккаунта; поэтому здесь
  их нет по умолчанию.
- Используй разумные интервалы, не создавай лишнюю нагрузку на сайт.

## Структура проекта

```
avito_watcher/
  config.py     — конфигурация (config.yaml + .env)
  scraper.py    — парсер выдачи Авито на Playwright
  filters.py    — доп. фильтры (цена, ключевые слова)
  storage.py    — SQLite-хранилище виденных ID
  notifier.py   — отправка в Telegram
  main.py       — цикл мониторинга
get_chat_id.py  — помощник для получения chat_id
```
