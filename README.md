# Silent Installer

Программа для Windows, которая **сама ставит пачку программ в тихом режиме**:
отмечаете в списке нужные (7-Zip, Adobe Acrobat Reader, Chrome…), перетаскиваете в окно их
установщики, нажимаете «Установить выбранное» — и программы ставятся по очереди без
окон, вопросов и кнопок «Далее».

- Каталог из 40 популярных программ с проверенными ключами тихой установки (`programs.json`).
- Установщики просто **перетаскиваются в окно** (файлы или целые папки) и копируются в `Distrib`.
- Для программ не из каталога **тип установщика определяется автоматически**
  (MSI, Inno Setup, NSIS, InstallShield, WiX, Advanced Installer…) и ключи подставляются сами.
- **Наборы**: сохраните список программ («Офис», «Бухгалтерия»…) и выбирайте его одним кликом.
- Видно, какие программы уже установлены (и какой версии); их можно пропускать.
- Ключи можно поправить прямо в таблице и сохранить в каталог.
- Лог каждой установки в папке `Logs` (для MSI — подробный лог msiexec).
- Работает и **без окна** — из командной строки, для скриптов и массовой установки.
- Ничего не нужно устанавливать: только Windows 10/11 и встроенный PowerShell.

## Как пользоваться

1. Скачайте программу: **Code → Download ZIP** (или архив `SilentInstaller.zip` из раздела Releases)
   и распакуйте, например, на флешку.
2. Запустите **`Start.bat`**.
3. Перетащите в окно установщики программ (или положите их в папку `Distrib`).
   Программы, для которых найден дистрибутив, отметятся галочками автоматически.
4. При необходимости выберите **набор** или отметьте программы вручную.
5. Нажмите **«Установить выбранное»** и подтвердите запрос прав администратора (UAC).

Окно само работает без прав администратора (чтобы в него можно было перетаскивать файлы из
проводника), а права запрашиваются один раз — в момент установки.

```
SilentInstaller\
├── Start.bat             ← запуск окна программы
├── Install-All.bat       ← установить всё из Distrib без окна
├── SilentInstaller.ps1
├── programs.json         ← каталог программ и ключей
├── presets.json          ← наборы программ
├── Distrib\              ← сюда кладутся установщики
│   ├── 7z2409-x64.exe
│   ├── AcroRdrDC2400221005_ru_RU.exe
│   ├── googlechromestandaloneenterprise64.msi
│   └── Office\setup.exe + configuration.xml
├── Logs\                 ← логи установки
└── lib\
```

Если нужной программы нет — просто перетащите её установщик в окно: тип определится

(двойной щелчок по ячейке «Ключи тихой установки») и, если нужно, сохраните их в каталог
(правый клик → «Сохранить ключи в каталог»).

### Подсказки по дистрибутивам

- **Adobe Acrobat Reader** — нужен полный офлайн-установщик `AcroRdrDC…exe`
  (страница Adobe для организаций), а не маленький онлайн-загрузчик.
- **Adobe Acrobat Pro** — распакуйте дистрибутив в `Distrib\Adobe Acrobat\` (там должен быть `setup.exe`).
- **Google Chrome** — лучше MSI для организаций `googlechromestandaloneenterprise64.msi`.
- **Microsoft Office** — папка `Distrib\Office\` с `setup.exe` из Office Deployment Tool и
  `configuration.xml` (создаётся на [config.office.com](https://config.office.com)).

## Каталог программ (`programs.json`)

```json
{
  "Name": "7-Zip",
  "Category": "Архиваторы",
  "Files": ["7z*.exe", "7z*.msi"],
  "Args": "/S",
  "Detect": ["7-Zip*"]
}
```

| Поле | Назначение |
|---|---|
| `Name` | Название программы (используется в наборах и командной строке). |
| `Category` | Категория в списке. |
| `Files` | Шаблоны имени файла установщика (`*` — любые символы). Шаблон с `\` ищется по пути внутри `Distrib`, например `Office\setup.exe`. Если подходит несколько файлов, берётся самый новый. |
| `Args` | Ключи тихой установки для `.exe`. Если не указаны — определяются автоматически. |
| `MsiArgs` | Ключи для `.msi` (по умолчанию `/qn /norestart`). |
| `Detect` | Шаблоны названия в «Программах и компонентах» — чтобы показать, что программа уже установлена. |
| `SuccessCodes` | Дополнительные коды выхода, которые считаются успешными. |
| `TimeoutMinutes` | Максимальное время установки (по умолчанию 60 минут). |
| `Notes` | Подсказка, которая показывается при наведении на название. |

Программы устанавливаются в том порядке, в котором они записаны в каталоге
(поэтому системные компоненты вроде Visual C++ стоят в начале).

### Автоопределение ключей

| Тип установщика | Ключи |
|---|---|
| MSI | `/qn /norestart` (через `msiexec /i`, с подробным логом) |
| Inno Setup | `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-` |
| NSIS (Nullsoft) | `/S` |
| WiX Burn | `/quiet /norestart` |
| InstallShield | `/s /v"/qn /norestart"` |
| Advanced Installer | `/exenoui /qn /norestart` |
| MSU (обновления Windows) | `/quiet /norestart` (через `wusa`) |
| MSIX / AppX | устанавливается для всех пользователей (`Add-AppxProvisionedPackage`) |
| `.bat`, `.cmd`, `.ps1` | запускаются как есть — удобно для своих сценариев установки |

## Командная строка

```powershell
# Список программ и найденных дистрибутивов
powershell -ExecutionPolicy Bypass -File SilentInstaller.ps1 -List

# Установить конкретные программы
powershell -ExecutionPolicy Bypass -File SilentInstaller.ps1 -Programs "7-Zip,Google Chrome,Adobe Acrobat Reader"

# Установить набор, пропуская уже установленное
powershell -ExecutionPolicy Bypass -File SilentInstaller.ps1 -Preset "Офис" -SkipInstalled

# Установить всё, что лежит в Distrib (то же делает Install-All.bat)
powershell -ExecutionPolicy Bypass -File SilentInstaller.ps1 -All -SkipInstalled

# Показать команды, ничего не устанавливая
powershell -ExecutionPolicy Bypass -File SilentInstaller.ps1 -All -DryRun
```

Дополнительно: `-Distrib <папка>` — другая папка с дистрибутивами (например, сетевая),
`-TimeoutMinutes <N>` — ограничение времени на одну программу, `-NoElevate` — не запрашивать
права администратора. Код выхода: `0` — всё успешно, `1` — были ошибки.

## Полезно знать

- **Коды выхода**: `0` — успех; `3010`/`1641` — успех, нужна перезагрузка (в конце программа
  предложит перезагрузить компьютер); `1638` — уже установлена такая же или более новая версия.
  Если установщик занят другой установкой (`1618`), попытка повторяется автоматически.
- **Пометка «Загружено из интернета»** снимается с установщиков автоматически, поэтому окна
  «Предупреждение системы безопасности» не появляются.
- **Сетевые диски**: программу можно запускать с сетевого диска (`Z:\`) — пути автоматически
  переводятся в UNC (`\\server\share`), чтобы их видел процесс с правами администратора.
- Программы, которые ставятся «на пользователя» (например, Telegram), установятся в профиль
  того пользователя, чьи учётные данные введены в окне UAC.
- Если установщик завис дольше `TimeoutMinutes`, он будет остановлен, и установка продолжится
  со следующей программы.

## Разработка

Тесты запускаются на каждом push в GitHub Actions на Windows: проверка синтаксиса в
Windows PowerShell 5.1, модульные тесты, **настоящая тихая установка** 7-Zip (EXE), PuTTY (MSI)
и Notepad++ (переименованный установщик — проверка автоопределения NSIS), а также создание окна
программы. Локально:

```powershell
.\tests\Run-Tests.ps1          # модульные тесты
.\tests\Run-Tests.ps1 -E2E     # + реальная установка (нужны права администратора)
```

Чтобы выпустить релиз с архивом `SilentInstaller.zip`, создайте тег вида `v1.0.0`.
