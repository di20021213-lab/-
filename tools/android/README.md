# APK для теста на телефоне

Обёртка вокруг офлайновой сборки: внутри та же `dist/index.html`, что
открывается в браузере, — вся игра и вся графика одной страницей. Сервер,
регистрация и почта не нужны, прогресс лежит в хранилище телефона.

Это сборка для проверки экономики и вида, а не для раздачи: подписана
отладочным ключом, поэтому телефон спросит разрешение на установку из
неизвестного источника.

## Что нужно

- JDK 17 и выше, Gradle 8
- Android SDK: `platforms;android-34`, `build-tools;34.0.0`
- переменная `ANDROID_HOME` на папку SDK

## Сборка

```
node tools/build-standalone.js          # обновить dist/index.html
cd tools/android && gradle assembleDebug
```

Готовый файл — `app/build/outputs/apk/debug/app-debug.apk`, копия лежит в
`dist/kolhoz.apk`.

Страница копируется в `assets` задачей `copyGame` при каждой сборке,
отдельной копии в репозитории нет — иначе она разойдётся с `dist`.

Зеркало Maven отвечает `429 Too Many Requests`, если дёргать его часто:
это ограничение по частоте, а не отсутствие файлов. Помогает просто
повторить сборку — кэш наполняется постепенно.
