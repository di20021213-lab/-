# Avito auto-responder

Ловит ссылки на объявления Авито из Telegram-каналов и отвечает по ним
сообщением из вашего аккаунта.

```
Telegram (Telethon, ваша сессия)
      │  сообщение в канале
      ▼
  парсер ссылок ──► SQLite (дедуп)
      │
      ▼
  очередь + лимиты (в час / в сутки / тихие часы / случайные паузы)
      │
      ▼
  Playwright + постоянный профиль Chromium
      │  открыть карточку → «Написать» → текст → отправить
      ▼
  отчёт обратно в Telegram
```

## Установка

```bash
pip install -r ../requirements.txt
playwright install chromium        # если Chromium ещё не стоит
cp ../config.example.yaml ../config.yaml
```

В `config.yaml` заполните:

* `telegram.api_id` / `api_hash` — берутся на https://my.telegram.org → *API
  development tools*.
* `telegram.sources` — каналы, откуда приходят объявления (`@username` или
  числовой id). Пустой список означает «слушать всё» — так лучше не делать.
* `templates` — тексты сообщений. Их несколько, бот берёт случайный;
  доступны `{title}`, `{price}`, `{seller}`, `{url}`.

## Первый запуск

```bash
python login.py     # откроется окно браузера — войдите руками
python main.py      # dry_run: true — бот показывает, что написал бы
```

`login.py` требует графического окружения. На сервере без монитора:
`xvfb-run -a python login.py` плюс VNC, либо залогиньтесь на десктопе и
скопируйте каталог `data/chrome-profile` на сервер.

Пароль вводите только вы, в окно браузера. В коде и конфиге его нет —
хранится сессия Chromium в `profile_dir`.

**Не снимайте `dry_run: true`, пока не посмотрите хотя бы десяток
сгенерированных сообщений в логе.** Снять: `/dry off` в Telegram или правка
конфига.

## Команды в Telegram

Пишите их в чат из `telegram.report_to` (по умолчанию — «Избранное»):

| Команда | Что делает |
|---|---|
| `/stats` | очередь, лимиты, что в базе |
| `/pause` / `/resume` | стоп / продолжить |
| `/dry on` / `/dry off` | режим «только показать» |
| `/send <ссылка>` | поставить объявление в очередь вручную |
| `/help` | список команд |

## Лимиты и поведение

* `max_per_hour` / `max_per_day` — жёсткие потолки, при упоре бот ждёт, а не
  пропускает объявление.
* `delay_min_s`…`delay_max_s` — случайная пауза между откликами, текст
  печатается посимвольно.
* `quiet_hours: [23, 8]` — ночью не пишет.
* Дубли по id объявления не отправляются повторно никогда (база `state.sqlite3`).
* У части объявлений чат отключён (только звонок) — такие помечаются
  `skipped`, это нормально.

## Капча и разлогин

Бот **не решает капчу и не маскируется**. Увидев проверку или форму входа, он
встаёт на паузу и пишет вам в Telegram. Вы проходите проверку руками в том же
окне браузера (или перезапускаете `login.py`) и отправляете `/resume`.

## Когда перестанет работать

Вёрстка Авито меняется, и кнопки/поля переезжают. Поэтому все селекторы лежат
в `config.yaml` в секции `selectors` — списками, сверху вниз до первого
совпадения. Если бот пишет «не найдено поле ввода чата»: откройте объявление,
DevTools → скопируйте актуальный селектор → добавьте первым в список. Код
трогать не нужно.

## Тесты

```bash
python tests/test_basics.py
```

Проверяют парсер ссылок, дедуп, лимиты, тихие часы и шаблоны на фейковом
браузере — без обращения к Авито.

## О рисках

Авито не любит автоматизацию и применяет антифрод. Гарантий, что аккаунт не
словит ограничение, нет ни у кого; консервативные лимиты в конфиге стоят
именно поэтому. Решение о запуске — ваше.
