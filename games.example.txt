# Список игр для охоты. По названию в строке.
# Пустые строки и строки с # пропускаются.
#
# Формат:  Название [| потолок [| нижняя граница]]
# Скормить генератору:
#     cp config.games.example.yaml config.yaml
#     .venv/bin/.venv/bin/python make_searches.py games.example.txt >> config.yaml
#
# ПРО ПОТОЛКИ. Они здесь намеренно щедрые — 8000 почти у всех. Это не оценка
# стоимости, а осознанное решение: сначала УВИДЕТЬ рынок, потом его сузить.
# На видеокартах я поступил наоборот — выставил цифры из головы, все они
# оказались ниже рынка, и из сотни объявлений прошло три. Второй раз так не
# делаем. Через неделю запусти `.venv/bin/python report.py` и выставь настоящие по
# колонке «советую».
#
# ПРО ЧИСЛО ИГР. За цикл проверяется ОДИН поиск, по очереди: нагрузка на адрес
# от длины списка не растёт, а вот частота проверки каждой игры делится. При
# цикле в 10-18 минут двадцать названий — это проверка каждой раз в 3-6 часов.
# Для вещи, которая всплывает раз в месяц, с запасом. Но список длиной в сотню
# уже растянет круг на сутки, так что лучше выкидывать то, что за месяц не
# выстрелило ни разу, чем набирать впрок.
