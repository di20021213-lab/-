# ЭТОТ СПИСОК СОБРАН ПО ДАННЫМ, А НЕ ПО ПАМЯТИ. Первая его версия была моей
# выдумкой: два десятка названий, которые я счёл редкими. Разведка рынка
# (scan_market.py) показала, что работает совсем другое.
#
# Что выяснилось за один обход:
#   · широкие сети оказались полезнее любого списка названий. По запросу
#     «Limited Run» пришло 55 объявлений — десятки РАЗНЫХ игр, которые я бы
#     не угадал никогда: R-Type Delta, TramSim, Onimusha, Sam & Max,
#     Green Lava Studios. Одним поиском накрывается весь этот пласт;
#   · рынок плотный. Основная масса стоит 3990-6990, медиана 5555. Разброс
#     «от 777 до 40500» оказался обманом: снизу витрины перекупов, сверху
#     коллекционки — то есть другой товар;
#   · объявления висят по неделе. Значит по этим ценам не берут: просят одно,
#     продаётся за другое. Потолки ниже поставлены по НИЖНЕЙ границе
#     наблюдаемого, а не по медиане — чтобы приходило только заметно дешёвое.
#
# ПРО ПОТОЛКИ. Это не «сколько игра стоит», а «дешевле чего мне интересно».
# Ставить их по медиане бессмысленно: под медиану подходит половина рынка, и
# поиск превращается в ленту. Потолок должен стоять НИЖЕ самой дешёвой цены,
# которую ты видел живьём, — тогда уведомление означает, что кто-то сбросил.
#
# Проверять просто: если за один цикл пришло четыре объявления, потолок высокий.
# Бот про это сам пишет в журнал («это уже лента, а не охота»).
#
# Числа ниже, кроме Star Wars, взяты из разведки — а она, как выяснилось,
# показывает верхушку выдачи, а не весь рынок. Дождись первых уведомлений и
# поправь по настоящим ценам.
#
# ПРО ПЛАТФОРМУ. В каждый сгенерированный поиск подставляются стоп-слова на
# чужие приставки: PS3/PS2/PSP, Xbox, Switch, Sega и прочие. Иначе широкая сеть
# вроде «Коллекционное издание» тащит что попало — первым уловом пришла
# Uncharted 2 для PS3. Требовать «ps4»/«ps5» в заголовке нельзя: половина
# объявлений платформу не пишет вовсе. Нужны Switch или Xbox — правь список
# EXCLUDE_PLATFORMS в make_searches.py и пересобирай конфиг.
#
# ПРО ЧИСЛО СТРОК. За цикл проверяется один поиск, по очереди. Шесть строк при
# цикле в 10-18 минут — это полный круг за час-полтора. Добавишь двадцать —
# круг растянется на полдня. Лучше держать список коротким и выкидывать то,
# что месяц не выстрелило.
